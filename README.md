# Mitul Thakur — Professional Portfolio

A responsive, animated portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive design, gradients, animations
- `script.js` — scroll reveal and cursor effects

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a public GitHub repository, for example `mitul-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live Pages URL.

## Customize
- Replace the `MT` initials block with your photo if desired.
- Update project descriptions/links in `index.html`.
- Update email and LinkedIn links in `index.html`.
